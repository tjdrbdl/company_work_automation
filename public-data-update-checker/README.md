# 공공 통계 원천 갱신일 확인 자동화

HTML 파싱과 KOSIS Open API 조회로 16개 대상의 원천 갱신일을 확인하는 운영 보조 노트북입니다.

## 구현 내용
- index.go.kr 4개 지표: 최근 갱신일과 입력예정일 추출
- KOSIS 12개 통계표: SEND_DE가 있는 항목의 최댓값 선택
- 요청 타임아웃 및 HTTP 오류 처리, 날짜 미발견 상태 구분
- (출처, 키)별 최신 확인 상태를 UTF-8 BOM CSV로 저장

OK는 갱신일 추출 성공을 뜻합니다. 최신성 기준 충족, 회사 DB 적재 완료, 실제 통계값 정확성을 검증하지 않습니다. CSV는 이력을 누적하지 않고 최신 상태를 덮어씁니다.

## 실행 방법 (Windows PowerShell)
```powershell
python -m pip install -r requirements.txt
$env:KOSIS_API_KEY = Read-Host '개인 KOSIS API 키'
python -m jupyterlab check_index_update.ipynb
```
같은 PowerShell 세션에서 실행하고 새 커널에서 셀을 순서대로 실행하세요. `.env.example`은 변수명 안내용이며 .env를 자동으로 읽지 않습니다. 실제 키를 노트북 셀에 입력하지 마세요.

## 공개용 변경
키를 환경변수로 분리하고 모든 실행 출력과 실행 번호를 제거했습니다. 요청 예외의 전체 URL과 API 오류 본문 출력을 제거했습니다. 회사 환경에 맞춘 인증서 패치와 셀 내부 자동 설치도 제거했습니다. 원본 파일은 보존했습니다.

## 한계 및 보완 후보
- 재시도, 스케줄러, 알림, 전회 대비 변경 감지 미구현
- CSV는 실패 시 이전 갱신일도 빈 값으로 대체함
- 날짜 유효성 및 KOSIS 응답 스키마 검증 보완 필요
- KOSIS 저장 키에 orgId를 포함하면 기관 간 tblId 충돌 예방 가능
- 응답 예시를 사용한 파싱 및 오류 처리 테스트 추가 권장
- 패키지 버전 고정 및 새 환경 재현 검증 전

## 실행 확인 범위
JSON 구조, 모든 코드 셀의 Python 문법, 원래 인증키와 사내 사용자 경로 제거, 출력 초기화, 원본 해시 보존을 확인했습니다. 인증키를 사용한 외부 API 호출과 노트북의 처음부터 끝까지 실행 및 화면 검수는 하지 않았습니다. 위 실행 방법으로 개인 키를 설정한 후 최종 연동 확인이 필요합니다.
